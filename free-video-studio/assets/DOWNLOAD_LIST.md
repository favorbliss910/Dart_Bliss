# Free sound effects & music to download

Put files in `sfx/` and `music/` using these names so the video builder can find them.

## Sound effects (`sfx/`)
Search these on **freesound.org** (tick *Creative Commons 0*) or **pixabay.com/sound-effects**:

| File name | Search term | Used for |
|---|---|---|
| `whoosh.wav` | whoosh / swoosh | scene transitions, camera moves |
| `pop.wav` | pop / bubble pop | text or object appearing |
| `boing.wav` | cartoon boing | jumps, surprises |
| `ding.wav` | ding / bell | ideas, reveals |
| `click.wav` | button click | buttons, UI |
| `crowd_gasp.wav` | crowd gasp | big reveals |
| `crowd_murmur.wav` | crowd murmur | town / group scenes |
| `rumble.wav` | earthquake rumble | danger, tension |
| `riser.wav` | riser / tension build | before a twist |
| `impact.wav` | cartoon impact / thud | falls, hits |
| `alarm.wav` | alarm buzzer | warnings |
| `footsteps.wav` | cartoon footsteps | walking |

Also free: **Kenney.nl → Audio** packs (CC0, direct ZIP downloads).

## Music (`music/`)
From **pixabay.com/music** (free, no attribution) or the **YouTube Audio Library**:
- `curious.mp3` — light, quirky (search: "quirky", "curious", "documentary light")
- `tense.mp3` — suspense (search: "suspense", "mystery")
- `upbeat.mp3` — happy ending (search: "upbeat ukulele", "happy")

Keep music quiet under the voice (the builder will duck it to about -20 dB).
