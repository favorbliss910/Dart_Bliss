# What If You…? — Prompt Book

| File | What it is |
|---|---|
| `PROMPT_BOOK.pdf` | The designed book: master prompt, story & visual system, 2D animation engine, sound design engine, all 300 sound principles, QA, templates, the Jupiter worked example, topic playbooks, full source code |
| `PROMPT_BOOK.md` | The same book as plain text, for pasting into a session |
| `MASTER_PROMPT.md` | Part I only: the paste-ready prompt + project card |
| `engine/` | The reusable rendering + sound engine (`example_jupiter/` = the finished Jupiter project) |
| `chapters/`, `build_book.py`, `book.css`, `make_pdf.js` | Book sources; rebuild with `python3 build_book.py <300_Sound_Design_Principles.pdf>` |

**New video:** paste `MASTER_PROMPT.md` (or the whole `PROMPT_BOOK.md`), fill in the project card, and upload the voiceover + music.
