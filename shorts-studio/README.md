# Shorts Studio

A production environment for **narrated animated story Shorts**. It is built from a frame-by-frame analysis of 9 high-performing reference Shorts (see [docs/ANALYSIS.md](docs/ANALYSIS.md)).

- **Ideas → scripts** with prompts that encode what makes those Shorts work: hooks, formats, escalation and endings.
- **Voice:** Kokoro TTS, **`am_michael`**, tuned to the references' pace (about 220 wpm).
- **Sound design:** 25 original synthesized SFX cued to the exact spoken word, generated mood music with pre-reveal drops, sidechain ducking, a broadcast voice chain, and -14 LUFS / -1 dBTP mastering.
- **Video:** your images or clips per beat, with camera moves, transitions, word-synced captions in the reference style, and number overlays.

## Setup (once)
Needs Python 3.10+ and ffmpeg (with libass).
```bash
cd shorts-studio
bash scripts/setup.sh          # installs packages, downloads Kokoro + Whisper, runs a voice test
```

## The workflow

```
1. IDEAS        prompts/01_idea_generator.md    →  10 scored ideas (JSON)
2. SCRIPT       prompts/02_script_writer.md     →  specs/<slug>.json  (beats, visuals, SFX, music)
3. REVIEW       prompts/03_retention_review.md  →  tighter hook, cut dead beats
4. PREVIEW      python -m studio.make_short specs/<slug>.json --preview
                → output/<slug>/shotlist.md has the exact length of every beat
5. VISUALS      prompts/04_visual_style.md      →  assets/<slug>/beat_01.png … (images or clips)
6. RENDER       python -m studio.make_short specs/<slug>.json
                → output/<slug>/final.mp4   (1080×1920, 30 fps, -14 LUFS)
```

Steps 1–3 work in any Claude chat: paste the prompt and fill in the `{{…}}` fields. Or automate them with the API:
```bash
export ANTHROPIC_API_KEY=...
python -m studio.ideas ideas --n 10 --themes "ocean mysteries, ancient engineering"
python -m studio.ideas script --idea-file ideas/<file>.json --pick 3 --review
```
Past ideas and specs are fed back into the generator, so it doesn't repeat itself.

## Try the demo
`specs/example_lighthouse.json` is a complete 40-second mystery-loop Short. Render it (beats with no visuals become labelled placeholder cards):
```bash
python -m studio.make_short specs/example_lighthouse.json
```

## Useful commands
| Command | What it does |
|---|---|
| `python -m studio.make_short SPEC --audio-only` | voice + SFX + music + master only (fast iteration on the script) |
| `python -m studio.make_short SPEC --preview` | quick low-res render to check the edit |
| `python -m studio.make_short SPEC --seed 7` | a different music variation (same seed = same music) |
| `python -m studio.sfx` | audition all 25 sound effects → `output/sfx_preview/` |
| `python -m studio.analyze_reference a.mp4 b.mp4` | break down any Short (transcript, pace, loudness, cuts, contact sheets); also compare your own renders |

## Spec cheat-sheet
```jsonc
{
  "title": "…", "slug": "…", "voice": "am_michael", "speed": 1.18,
  "mood": "mystery",              // mystery|curious|tension|comedy|reflective|epic|none
  "music_file": null,             // or a licensed track path
  "caption_style": {"words_per_chunk": 2, "uppercase": false},   // optional overrides
  "beats": [{
    "vo": "Narration line.",      "say": "optional phonetic version",
    "visual": "shot description", "motion": "push_in", "transition": "whip",
    "emphasis": ["word"],         "overlay": "208 FT",  "music": "drop",
    "sfx": [{"name": "impact", "on_word": "word", "gain_db": -10}]
  }]
}
```
Full field reference: [prompts/02_script_writer.md](prompts/02_script_writer.md). Sound details: [docs/SOUND_DESIGN.md](docs/SOUND_DESIGN.md).

## Voice options
- `"voice": "am_michael"` is the house narrator.
- `"voice": "am_michael:0.8,am_onyx:0.2"` blends in a little depth.
- `"speed"`: 1.10 is calmer (philosophy or history); 1.18 is the default; 1.25 suits 15-second teasers.
- Per-beat `"speed"` lets you slow down the final line for weight.

## Layout
```
prompts/   the four prompts (ideas, script, review, visual style)
docs/      ANALYSIS.md (reference breakdown), SOUND_DESIGN.md
specs/     one JSON per Short
assets/    visuals per Short: assets/<slug>/beat_NN.png|mp4
studio/    the pipeline (tts, align, sfx, music, mix, captions, video, make_short, ideas, analyze_reference)
sfx_library/  optional: your own recorded SFX override the synthesized ones
models/    Kokoro + Whisper (downloaded by setup, not committed)
output/    renders (not committed)
```
